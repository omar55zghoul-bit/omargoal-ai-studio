OmarGoal AI Studio — iPhone Safari MVP
1) Upload index.html to the root of a public GitHub repository.
2) GitHub repo > Settings > Pages > Deploy from a branch > main > /(root) > Save.
3) Open https://YOUR-USERNAME.github.io/YOUR-REPO/ in Safari.
Works locally in Safari: script prompt preparation, SRT generation, video preview, PNG thumbnail, speech playback, mic recording, local project save/export.
Not included: integrated AI inference, automatic translation, full MP4 video editing/export. These need a compatible processing engine or backend and device testing.
